# USC IMPACT LAB Website

Static starter website for USC IMPACT LAB, designed for straightforward GitHub Pages deployment.

## Structure

- `index.html` - site content and page sections
- `styles.css` - responsive layout and USC-inspired visual system
- `script.js` - mobile navigation behavior
- `assets/` - favicon and visual assets

## Brand Notes

The site uses official USC digital color values:

- USC Cardinal: `#990000`
- USC Gold: `#FFCC00`

The header and affiliation strip currently use text-based logo placeholders. Before public launch, replace those placeholders with approved USC and USC Viterbi logo files from the official identity resources available to USC faculty and staff.

Useful references:

- USC brand colors: https://identity.usc.edu/identity/color/
- USC marks and logotypes: https://identity.usc.edu/logos/
- USC Viterbi identity assets: https://viterbischool.usc.edu/identity/graphic-identity-assets/

## Editing Content

Update the placeholder copy in `index.html`:

- Lab description in the hero and About sections
- Research themes and projects
- People cards
- Publication entries
- News posts
- Contact email, location, and GitHub URL

## GitHub Pages Deployment

1. Push this folder to the lab GitHub repository.
2. In the repository settings, open **Pages**.
3. Set the source to deploy from the default branch.
4. Select the repository root as the publishing folder.

For a custom domain, add a `CNAME` file at the repository root containing the domain name, then configure DNS through the domain provider.
